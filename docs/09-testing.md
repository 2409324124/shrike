## Agent eval corpus (`fixtures/bugs`)

Each bug is a folder with a patch on top of a fixture, the user's complaint in plain words, the expected root-cause `file:line`, and a scenario that fails before the fix and passes after.

```
fixtures/bugs/001-wrong-field-name/
├── bug.patch          # applied to fixtures/todo-app
├── complaint.txt      # "When I click Add Todo nothing shows up"
├── expected.json      # { "file": "server/todos.controller.ts", "line": 18, "category": "contract-mismatch" }
└── scenario.json      # steps + expect
```
